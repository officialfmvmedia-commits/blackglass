# GLASSBREAK | Hack Tracker
Independent public-data OSINT tracking on-chain movement of addresses publicly tied to the Lazarus Group (OFAC SDN DPRK programs, FBI IC3 PSA250226, FBI Harmony statement). Pipeline: `pipeline/run.py` (stdlib Python) runs every 15 min on GitHub Actions and writes `data/*.json`, `feed.xml`, `feed.json`.
Not affiliated with any government. Scores are heuristic resemblance, not attribution.
